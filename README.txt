TRF2 Inventário + PCTT + OCR
1) Abra index.html em navegador moderno.
2) Clique em Carregar PCTT (Excel) e selecione a TabelaPCTTabril2026.xlsx.
3) Fotografe/seleciona o documento ou PDF.
4) Clique Ler documento com OCR.
5) Revise o texto OCR, clique Classificar pelo PCTT.
6) Escolha o resultado correto.
7) Revise os campos e clique Adicionar registro.
8) Exporte Excel.

Observação: esta versão usa o PCTT carregado no navegador e não envia a foto para um servidor próprio. O OCR usa Tesseract.js via CDN.
